I’ll guide you through setting up remote access to your Ubuntu system in India from the USA using your existing Tailscale connection, without rebooting, shutting down, updating, upgrading, or stopping btop.
We’ll do this in stages. First, establish a safe remote connection; then configure graphical access if needed.
Step 1 — Check your existing Ubuntu system
Open a new terminal. Do not close the terminal running btop.
Run these commands one by one:
# 1. Check Tailscale connection
tailscale status
# 2. Get this machine's Tailscale IP
tailscale ip -4
# 3. Check SSH service status
systemctl is-active ssh
# 4. Check whether SSH is listening
ss -lnt | grep ':22 '
These commands only inspect the system. They do not change its configuration.
Step 2 — Check your USA device
On the device you’ll use in the USA:

• Install/open Tailscale..
• Sign in to the same Tailscale network..
• Find the Ubuntu machine in the device list..
• Note the Ubuntu machine’s Tailscale IP address..
Step 3 — Connect using SSH if it is already enabled
From the USA device, open a terminal and run:
ssh YOUR_USERNAME@TAILSCALE_IP
Replace YOUR_USERNAME with your Ubuntu username and TAILSCALE_IP with the address from Step 1.
If SSH is inactive or unavailable, don’t enable or install anything yet. We’ll check the existing configuration first to avoid disturbing your running workloads.
Step 4 — Choose your desktop access method
SSH gives you terminal access, not the full graphical desktop. For desktop control, we need to check which services and desktop environment are already present.
Run this on Ubuntu:
# Check desktop environment
echo "$XDG_CURRENT_DESKTOP"
echo "$XDG_SESSION_TYPE"
# Check existing remote desktop services
systemctl is-active xrdp
systemctl is-active gnome-remote-desktop
systemctl is-active sunshine
# Check whether the relevant programs exist
command -v xrdp
command -v sunshine
An inactive result does not necessarily mean the software is missing.
